    Built-in tiles

    Untick a tile to hide it from the popup. Hidden tiles stay listed here so you can bring them back at any time.

    Backup

    Export your custom tiles to a JSON file, including uploaded icons, or import a file created on another machine. Importing never overwrites existing tiles; duplicates are skipped.

    Custom tiles appear first in the popup grid, in the order shown here — use the arrows to rearrange them. Tiles and settings sync with your Chrome profile; uploaded icons are stored on this device only, while icons added by URL are loaded from that address.
